# Student Performance Analyzer

## Description

A Python application that collects student information,
classifies academic performance, and calculates summary
statistics.

## Features

- Collects information for at least five students
- Stores records using a list of dictionaries
- Uses a tuple for grade categories
- Validates student scores between 0 and 100
- Classifies grades using conditional statements
- Calculates average, highest, and lowest scores
- Counts passing and failing students
- Identifies the top-performing student

## Requirements

- Python 3

## How to Run

1. Open a terminal in the project directory.
2. Run the command:

   python main.py
